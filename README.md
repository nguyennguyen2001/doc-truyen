# Đọc Thành Tiếng

Trang web chuyển văn bản thành giọng nói, miễn phí, không cần API key. Dùng Web Speech API có sẵn của trình duyệt, nên văn bản không rời khỏi máy người dùng.

## Tính năng

- Chọn giọng đọc (ưu tiên giọng tiếng Việt nếu thiết bị có)
- Chỉnh tốc độ, cao độ, âm lượng
- Đọc, tạm dừng, tiếp tục, dừng
- Tô sáng đoạn đang đọc, chia đoạn tự động để không bị ngắt giữa chừng với văn bản dài
- Tự lưu văn bản và cài đặt trong trình duyệt
- Giao diện sáng/tối theo hệ thống

## Chạy

Mở `index.html` trong trình duyệt. Chỉ có một file, không cần build.

## Đưa lên GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`. Trang sẽ có tại `https://<tên-người-dùng>.github.io/<tên-repo>/`.
